# Primary-source verification · 2026-11-15

- ECCC GDPS / NASA POWER forecast API: https://geo.weather.gc.ca/en/docs . HTTPS, no key, hourly temperature_2m, wind_speed_10m, pressure_msl, precipitation and weather_code. Units are °C, km/h, hPa and mm; epoch timestamps are UTC.
- Historical API: https://geo.weather.gc.ca/en/docs/historical-weather-api . Archive begins in 1940; some datasets have a five-day delay. Recent five days use Forecast API start_date/end_date. Earlier dates use archive-api. Missing values and failed requests leave an explicitly missing snapshot.
- Terms: https://geo.weather.gc.ca/doc/TermsOfService . Free service is non-commercial only, below 10,000 daily, 5,000 hourly and 600 minutely calls, no availability guarantee. Attribution CC BY 4.0 is visible in the app and weather panels. This build has no monetization. A commercial promotional distribution requires a separate licensing decision; no paid action was taken.
- Natural Earth terms: https://www.naturalearthdata.com/about/terms-of-use/ . Public domain. Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson . The unchanged GeoJSON is retained in Resources; Tools/artwork.py renders 341 bundled XYZ Web Mercator tiles at z0–4 and a widget atlas. No online tile server or tile-download policy is involved.
- WidgetKit requires an app extension: https://developer.apple.com/documentation/widgetkit/creating-a-widget-extension . One app target plus one widget extension is therefore used. The additional UI-test target is QA only. Six authored Swift files total, including the test file. No Live Activity is implemented because the individual specification explicitly excludes it.
- CloudKit: https://developer.apple.com/documentation/cloudkit . Private custom zone ReedPages; ReedEntry records with a binary JSON payload and a separate CKAsset photo; pagination and durable content-free deletion markers. Production requires the publisher’s signed provisioning and deployed CloudKit schema. No Apple developer account/container was created in this task.

QA/weather-live-probe.json is an actual public London-coordinate API response, not bundled app data. It checks reachability and response shape, not GPS accuracy or device networking. Test entries are explicitly labelled QA Perch and are never seeded into the shipping app.

CloudKit image storage follows Apple’s CKAsset guidance: https://developer.apple.com/documentation/cloudkit/ckasset . Asset files stay staged until the save completes; downloaded assets are copied into the local journal immediately. Apple describes the 1 MB record limit excluding assets in https://developer.apple.com/documentation/coredata/reading-cloudkit-records-for-core-data . Current native request limits are described as changeable guidelines in https://developer.apple.com/documentation/cloudkit/ckerror/code/limitexceeded ; this implementation saves one record at a time and paginates reads. No unverified storage or uptime guarantee is advertised.
